# Hojas de Pines

Página para armar hojas de pines: acomodas tus imágenes en círculos de 59 mm
y descargas un PDF listo para imprimir y recortar.

**Úsala aquí:** https://neofrek.github.io/hojas-de-pines/

- Funciona en el celular y en la computadora; no necesita cuenta.
- Las imágenes nunca salen de tu dispositivo: todo pasa en el navegador.
- Al imprimir, elige **"Tamaño real" / 100 %**, no "Ajustar a la página".

## Para editarla

- `pines.html` es la fuente.
- `python3 build.py` arma `docs/index.html`, que es lo que publica GitHub Pages
  y también funciona sin internet si lo abres con doble clic.
